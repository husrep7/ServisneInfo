# ServisneInfo

Aplikacija za praćenje i obavještavanje o komunalnim ispadima (voda, struja, gas, grijanje, telekom) u Sarajevu.

## Struktura

- `apps/backend` — Fastify API, scraperi, geofencing, push notifikacije
- `apps/mobile` — Expo/React Native mobilna aplikacija
- `apps/web` — React/Vite web aplikacija (deploy na Vercel)

Vidi [SETUP.md](./SETUP.md) za lokalno pokretanje.
